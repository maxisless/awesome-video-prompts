## IMAGE 2.5 生图提示词（可一键使用）

生成一张 `16:9` 横向构图的苹果电脑桌面图，仿 macOS 经典简洁渐变桌面背景：柔和、干净的蓝紫、粉橙渐变，不出现真实品牌文字、菜单栏、Dock 栏、文件名、日期或水印。画面左侧整齐排列两列常用 App 图标，共 8–10 个；图标是清晰、统一尺寸、圆角方形的通用应用图标，有轻微桌面图标投影，但不包含可辨认的商标、文字或乱码。画面右侧是一位全身可见的年轻成年东方女性敦煌飞天舞者，真人感强，面部自然、皮肤和手脚比例真实；她姿态优雅、轻盈，处于敦煌舞的起始 pose，乌黑长发与飘逸披帛、传统飞天服饰自然垂落并轻轻飘动。飞天与桌面图标处在同一奇幻写实空间：她像从桌面背景中走出来，但没有遮挡左侧图标。光线柔和，人物边缘干净，构图左侧留给图标、右侧留给人物，固定正视角，整体简约、高级、真实摄影与精致数字桌面融合的质感。

## 视频提示词

以参考图 `Image1` 为唯一视觉基准，固定机位、单一连续镜头。画面为高真实感的敦煌飞天与 macOS 桌面融合场景：右侧的年轻成年东方女性飞天具有自然真人五官、真实皮肤纹理和可信的身体比例，衣料、披帛、妆发与参考图保持一致；左侧为参考图中原有的平面 UI 图标区域，背景是一面可被扯动的经典渐变桌面幕布。整体是精致但有生活感的写实奇幻短片，不是卡通或二维动画。

**0–3 秒：从容起舞**

飞天在画面右侧轻盈跳舞，动作优雅、自然、具有敦煌舞的手臂与身姿韵律。她的一只脚稳稳踩下时，意外扯动身后的渐变桌面幕布；幕布产生真实柔软材质的张力和轻微抖动，但 macOS 渐变图案保持可辨认。

**3–5 秒：意外发生**

幕布的抖动传到左侧区域，左侧原有的多个平面 UI 图标被震落，从原位置依次掉到地面。图标保持扁平图形质感，不变成人物或立体物件；落地时有轻巧、诙谐的节奏感。飞天愣住，吓得双手捂住嘴，立刻停止舞蹈。

**5–8 秒：慌忙补救**

她快步跑到画面左侧，弯身把地上的图标一个个按回原来的位置。由于太着急，两个图标略微按歪：仍贴在幕布原有区域附近，但角度或位置有轻微错位。她发现后短暂停顿，却来不及修正。动作轻快、有真实重心变化，不夸张跑跳。

**8–10 秒：若无其事地收场**

她迅速回到画面右侧，重新摆回开始时的舞蹈 pose，努力维持端庄；表情是有点尴尬、勉强微笑。轻风吹来，她的衣服和披帛自然飘动，渐变桌面幕布也轻轻起伏；那两个稍微按歪的图标仍可见，但不抢镜。停在她强装镇定的 pose 上结束。

### 画面与表演

- 保持参考图的人物身份、服装、发型、妆容、macOS 渐变桌面布局、图标样式与色彩关系稳定。
- 飞天要有真人感：自然面部微表情、真实手部和脚部比例、衣料受重力与风力影响、自然落脚与转身。
- 喜剧来自“舞蹈意外碰掉图标后努力装作没事”，不是滑稽夸张的肢体表演。
- 固定机位，中景到全身构图；不推拉、不摇移、不切镜、不改变透视。

### 声音与音乐

开头使用安静、典雅的传统敦煌风格音乐，配合舞蹈节奏。幕布被扯动和图标落地时加入轻微丝绸抖动与清脆、克制的提示音；从事故发生后，音乐自然转成轻松诙谐、略带俏皮的曲风。结尾保留一阵轻风和衣料、披帛的细微摩擦声。
