# 敦煌飞天误触 UI

> 模型：Seedance 2.0
>
> 形态：参考图生视频。将上传的画面作为 `Image1`；保持其中飞天人物、左右 UI 图标、幕布背景、色彩、构图和固定机位一致。

## 视频提示词

以参考图 `Image1` 为唯一视觉基准，固定机位、单一连续镜头。画面为高真实感的敦煌飞天舞台场景：右侧的年轻成年东方女性飞天具有自然真人五官、真实皮肤纹理和可信的身体比例，衣料、披帛、妆发与参考图保持一致；左侧为参考图中原有的平面 UI 图标区域，背景是一面带有图标的丝质幕布。整体是精致但有生活感的写实奇幻短片，不是卡通或二维动画。

**0–3 秒：从容起舞**

飞天在画面右侧轻盈跳舞，动作优雅、自然、具有敦煌舞的手臂与身姿韵律。她的一只脚稳稳踩下时，意外扯动身后的幕布；幕布产生真实丝绸张力和轻微抖动。

**3–5 秒：意外发生**

幕布的抖动传到左侧区域，左侧原有的多个平面 UI 图标被震落，从原位置依次掉到地面。图标保持扁平图形质感，不变成人物或立体物件；落地时有轻巧、诙谐的节奏感。飞天愣住，吓得双手捂住嘴，立刻停止舞蹈。

**5–8 秒：慌忙补救**

她快步跑到画面左侧，弯身把地上的图标一个个按回原来的位置。由于太着急，两个图标略微按歪：仍贴在幕布原有区域附近，但角度或位置有轻微错位。她发现后短暂停顿，却来不及修正。动作轻快、有真实重心变化，不夸张跑跳。

**8–10 秒：若无其事地收场**

她迅速回到画面右侧，重新摆回开始时的舞蹈 pose，努力维持端庄；表情是有点尴尬、勉强微笑。轻风吹来，她的衣服和披帛自然飘动，幕布也轻轻起伏；那两个稍微按歪的图标仍可见，但不抢镜。停在她强装镇定的 pose 上结束。

### 画面与表演

- 保持参考图的人物身份、服装、发型、妆容、场景布局、图标样式与色彩关系稳定。
- 飞天要有真人感：自然面部微表情、真实手部和脚部比例、衣料受重力与风力影响、自然落脚与转身。
- 喜剧来自“舞蹈意外碰掉图标后努力装作没事”，不是滑稽夸张的肢体表演。
- 固定机位，中景到全身构图；不推拉、不摇移、不切镜、不改变透视。

### 声音与音乐

开头使用安静、典雅的传统敦煌风格音乐，配合舞蹈节奏。幕布被扯动和图标落地时加入轻微丝绸抖动与清脆、克制的提示音；从事故发生后，音乐自然转成轻松诙谐、略带俏皮的曲风。结尾保留一阵轻风和衣料、披帛的细微摩擦声。

### 负面提示词

卡通动画、二维纸片人物、过度 CG 感、夸张滑稽表演、快速甩头、镜头运动、转场、镜头切换、人物漂浮失重、人物脸部漂移、身份变化、手指或脚部畸形、肢体比例变化、服装变形、图标变成人物或生物、图标文字乱码、图标数量大幅变化、幕布变成墙体或舞台布景、过度景深、强烈镜头光晕、水印、字幕、额外人物。
